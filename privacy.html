Privacy Policy

Last updated August 3, 2026

The short version: SpaceWise runs entirely on your Mac. It reads file names, paths, and sizes to figure out what's using your storage — it never reads file contents, and it doesn't send your data anywhere unless you explicitly choose to activate a paid license, in which case only the license key itself is checked against our payment provider.

1. What SpaceWise does on your device

SpaceWise scans folders you already have access to and records, locally, three things about each item it finds: its file path, its size, and when it was last modified or accessed. This data is stored in a local database on your Mac (in your user Application Support folder) and is never transmitted anywhere.

SpaceWise does not open, read, or inspect the contents of your files. It never uploads a file, a file listing, or any derived data to any server as part of normal scanning or cleanup.

2. What we don't collect

  • No analytics or usage telemetry by default
  • No account, email address, or sign-in required to use the app
  • No file contents, ever
  • No location data, no device fingerprinting, no advertising identifiers

3. The one network request SpaceWise can make

If you choose to activate an optional support license or a business license, SpaceWise sends your license key to our payment processor (Lemon Squeezy) to confirm it's valid. That's the only outbound network request the app makes, and it only happens if you initiate it from the Settings or Findings screen. You can verify this yourself with a network monitor like Little Snitch.

Lemon Squeezy processes payment and billing information under its own privacy policy, available at lemonsqueezy.com/privacy. SpaceWise never sees or stores your payment details.

4. Rules database updates

SpaceWise's classification rules (the database that recognizes things like Ollama model folders or Xcode caches) may be periodically fetched from a static, public JSON file we host, so the app can recognize new software without requiring an app update. This request contains no information about you or your files — it's a plain, unauthenticated file download, same as loading any public webpage.

5. Data you control

Everything SpaceWise stores lives in a local SQLite database on your Mac. You can delete it at any time by removing the app's Application Support folder, or by uninstalling the app. Nothing persists on any server we control, because nothing is ever sent to one.

6. Changes to this policy

If this policy changes in a way that affects what data leaves your device, we'll update this page and the "Last updated" date above. Given the local-only architecture is a core product commitment (see our positioning), we don't expect this to change in any way that compromises it.
