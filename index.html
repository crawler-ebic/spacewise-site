The bug we couldn't ignore

macOS Storage reported 65 GB used by "Applications." The Applications folder itself held only 11 GB. The missing 54 GB turned out to be a wallpaper download cache, buried three folders deep in a system Library directory — invisible to Finder, invisible to Storage Management, invisible to every cleaner we tried.

No existing tool would have flagged it, let alone explained it. That gap — between what macOS reports and what you can actually find — is the whole reason SpaceWise exists.

How it works
