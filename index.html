The bug we couldn't ignore
54 GB

missing, and no way to find it

macOS Storage reported 65 GB used by "Applications." The Applications folder itself held only 11 GB. The missing 54 GB turned out to be a wallpaper download cache, buried three folders deep in a system Library directory — invisible to Finder, invisible to Storage Management, invisible to every cleaner we tried.

That gap — between what macOS reports and what you can actually find — is the whole reason SpaceWise exists.

How it works

FAQ

Common questions

What data does SpaceWise send anywhere?
None, by default. SpaceWise reads file paths and sizes to figure out what's on disk — it never opens or reads file contents, and makes no network requests except an optional, explicit license check if you choose to activate a support license. You can verify this yourself with Little Snitch or Activity Monitor's network tab.
Why is "System Data" so large, and can SpaceWise explain all of it?
Not entirely — and we say so rather than pretending otherwise. Some of it (Time Machine local snapshots, the sealed system volume, swap space) is macOS-level overhead that no third-party tool can fully itemize, Apple's own Storage panel included. SpaceWise categorizes everything it legitimately can, and clearly labels the remainder instead of leaving it as an unexplained gap.
Why isn't this on the Mac App Store?
The App Store's subscription and in-app-purchase rules don't map cleanly onto an honor-system model where nothing is ever actually locked. Direct download keeps the model honest and keeps Apple's 15–30% commission out of a price that's already deliberately low. (The current build is a pre-notarization beta — see the instructions at the top of this page; a fully notarized build is coming very soon.)
How do the Safe / Review / Leave alone ratings work?
Every item is checked against a rules database and a separate safety engine with hard-coded protections for sensitive locations — Documents, Desktop, personal media, credentials like SSH keys and keychains, cloud-synced folders, and Messages and Mail data. Unrecognized items are always rated at least "Review first," never Safe by default, and protected locations can't be selected for one-click deletion no matter what a rule claims.
What are the system requirements?
macOS 14 (Sonoma) or later, on either Apple Silicon or Intel — the download is a universal binary. It needs Full Disk Access to see the folders macOS protects, which you grant once in System Settings.
