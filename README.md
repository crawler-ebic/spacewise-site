# spacewise-site

The public marketing site for SpaceWise, served via GitHub Pages.

This repo is intentionally separate from the app's source code (which
lives in the private `crawler-ebic/spacewise` repo) — GitHub Pages
requires a public repo on the free plan, and the app source shouldn't be
made public just to get free landing-page hosting.

Live at: https://crawler-ebic.github.io/spacewise-site/

To update: edit `index.html` / `privacy.html` / `eula.html` here, or copy
the latest versions from `docs/` in the main `spacewise` repo.
